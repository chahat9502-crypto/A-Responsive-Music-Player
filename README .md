# NeonWave Music Player

NeonWave is a modern and responsive web-based music player created using HTML, CSS, and JavaScript.

## Features

- Play, pause, next, and previous song controls
- Song title, artist name, album cover, and duration
- Progress bar with seek functionality
- Volume control and mute option
- Playlist, shuffle, repeat, and autoplay
- Favorite songs using Local Storage
- Dark and light themes
- Smooth animations
- Responsive design for mobile and desktop

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage

## How to Run

1. Download the project files.
2. Open the project folder in VS Code.
3. Open `index.html` in a browser.

## Add Music

Add MP3 files to the `audio` folder and cover images to the `assets` folder. Then add the song details inside the `songs` array in `script.js`.
